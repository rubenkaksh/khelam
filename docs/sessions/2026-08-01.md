## Decisions
- **Feature modules own their vertical slice** (ADR-0004): `lib/features/<feature>/` holds models, service interface, adapters, bloc, views, widgets, DI. Shared infra stays global (`lib/core/network/`); atomic widgets in `lib/ui/common/`; theming `lib/ui/core/`; navigation `lib/ui/navigation/`.
- **Pass-through repositories are banned** (extends ADR-0001): cubits depend on the service interface; only repositories with real logic return.
- **Routes provide their own cubit** via `BlocProvider` from the feature's DI registry; `app.dart` no longer lists features.
- **Home = placeholder** (login still routes there); meta-demo content deleted with the template chain.
- **Mock adapter behavior unchanged** (still ignores requested turfId — C5 adapter-drift was NOT in the top recommendation scope; noted for a future pass).
- **Revenue stat stays booking-payload-based** (₹0 in API mode) — backend must supply booking details on list slots; documented in code + CONTEXT.md.
- Kept the `!`-free strict rule: all rewritten usages use `if case` typed patterns / `?.` / `??`.
