## Decisions
- Rule lives in the **project** AGENTS.md only (not global) — user chose khelam-scoped.
- Convention: `docs/sessions/YYYY-MM-DD.md`, one dated file per day, kept as history.
- Maintenance: create at the start of the first session of the day; update continuously (after each task/decision/commit); read it at the start of every session.
- Booking iteration design decisions (from prior session, still valid): 10-digit Indian mobile (`^[6-9]\d{9}$`), `+91` prefix, `customerPhone` on Booking, atomic common widgets in `lib/ui/common/` for the forkable parent.
- API layer decisions:
  - `.env` stays committed (pubspec asset requirement; contents are dev-only defaults, no secrets).
  - Env access goes through `envValue` (lib/di/env_config.dart) so widget tests never hit `NotInitializedError`.
  - Booked-ness on the schedule screen derives from `slot.status` (list endpoint has no booking object); `bookedBy` supplies the customer name.
  - Booking keeps returning `void` from the service; the cubit refetches — avoids stale partial data from the book response (which lacks slot times).
  - DTO status strings map via `SlotStatus.values.byName` (fail fast on unexpected server values).
