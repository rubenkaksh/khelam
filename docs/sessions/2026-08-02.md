## Decisions
- Restore = `AuthService.init()` in `main` reading `{access_token, user}` JSON from secure storage; API impl re-attaches bearer; cubit emits authenticated with the restored user (profile persisted alongside the token so the UI has a full user without a `/auth/me` call). Mock mode restores nothing (no stored session used; sign-in per launch in dev).
- idToken-null guard lives in `AuthApiService` (friendly message pointing at `GOOGLE_SERVER_CLIENT_ID`), NOT the cubit — the mock service must succeed without an idToken (serverClientId is still a placeholder).
- `AuthService.login()` in API mode throws `AuthException('Email/password login is not wired to the backend yet')` — no `/auth/login` contract yet.
- Schedule + login remain public routes; booking/home require auth (user re-confirmed).

## Blockers
