## Objective

Implement https://github.com/rtk-ai/rtk into khelam as a DRY-RUN (runs alongside the existing setup, not replacing it); start collecting usage data (with-rtk vs without-rtk) for the comparison report (C17).

## ✅ Complete

1. **rtk binary installed** — v0.42.4 via Homebrew (`rtk-ai/tap/rtk`)
2. **OpenCode plugin configured** — `~/.config/opencode/plugins/rtk.ts` transparently rewrites bash commands via `rtk rewrite`
3. **Data collection script created** — `scripts/rtk_metrics.sh` saves daily JSON to `docs/rtk-data/YYYY-MM-DD.json`
4. **Documentation added**:
   - `docs/rtk-data/README.md` — explains data collection, JSON format, analysis plan
   - `docs/rtk-data/baseline-comparison.md` — initial with/without comparison (git status: 46.3% savings, flutter analyze: 0% — output already minimal)
   - `docs/rtk-data/2026-08-13.json` — first day's metrics (4 commands, 34% avg savings, 195 tokens saved)
   - `AGENTS.md` — added "RTK (dry-run)" section explaining setup, usage, data collection
5. **Feature branch created** — `feat/rtk-dry-run` with commit `c581ec8`
6. **Acceptance bar met** — rtk runs alongside existing tooling, does NOT replace scripts/, agent-tools, or pre-commit gate; data collection infrastructure ready for C17 analysis
